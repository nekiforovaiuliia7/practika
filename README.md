# practika

Отчет по практике: Приложение для учета финансов на Flask  


1. **Планирование**  
   - Этапы: проектирование → БД → операции → отчеты → безопасность → деплой.  
   - Ошибка: не учтены валютные операции (только RUB в ТЗ).  

2. **Проектирование БД**  
   - Таблицы:  
     - `Пользователи` (id, email, хеш_пароля)  
     - `Счета` (id, название, баланс, валюта, id_пользователя)  
     - `Транзакции` (id, сумма, тип [доход/расход], категория, дата, id_счета).  
   - Проблема: не было связи транзакций со счетами (исправил добавлением `account_id`).  

3. **Базовый функционал**  
   - Реализовано:  
     - Создание счетов  
     - Добавление операций (+ фильтры по дате/категориям)  
     - Баланс в реальном времени  
   - Ошибка: при удалении счета транзакции не удалялись (нарушалась целостность данных).  

4. **Интерфейс**  
   - Дашборд: графики расходов по категориям (Chart.js), история операций.  
   - Проблема: нет подтверждения операций → случайные удаления.  

5. **Дополнительные функции**  
   - Автоматические категории (еда, транспорт и т.д.).  
   - Экспорт в CSV/XLSX.  
   - Ошибка: при большом объеме данных экспорт "падал".  

6. **Тестирование**  
   - Найдены уязвимости:  
     - Доступ к чужим счетам через подмену `account_id` в URL  
     - XSS в названии категорий  
   - Решение: проверка прав доступа + экранирование вывода.  

7. **Деплой**  
   - Развернуто на VPS (Nginx + Gunicorn).  
   - Проблемы:  
     - Нет резервного копирования БД  
     - Медленные отчеты при 10k+ записей  

---

#### **Рекомендации по исправлению ошибок:**  

1. **Безопасность**  
   - Шифровать балансы в БД:  
     ```python  
     from cryptography.fernet import Fernet  
     encrypted_balance = cipher_suite.encrypt(str(balance).encode())  
     ```  
   - Добавить двухфакторную аутентификацию для критических операций.  

2. **Оптимизация БД**  
   - Внедрить каскадное удаление:  
     ```python  
     class Account(db.Model):  
         transactions = db.relationship('Transaction', cascade='all, delete')  
     ```  
   - Добавить индексы для частых запросов (дата, категория).  

3. **Валидация данных**  
   - Запрещать отрицательный баланс:  
     ```python  
     if transaction.type == "расход" and amount > account.balance:  
         flash("Недостаточно средств")  
     ```  
   - Проверять уникальность названий счетов у пользователя.  

4. **Производительность**  
   - Кэшировать отчеты:  
     ```python  
     @cache.memoize(timeout=3600)  
     def generate_monthly_report(user_id):  
         # сложные расчеты  
     ```  
   - Добавить пагинацию для истории операций.  

5. **Резервное копирование**  
   - Автоматические бэкапы БД (каждые 24 часа):  
     ```bash  
     crontab -e  
     0 3 * * * pg_dump finance_db > /backups/dump_$(date +\%F).sql  
     ```  

6. **Юзабилити**  
   - Добавить подтверждение для удаления:  
     ```javascript  
     function confirmDelete() {  
         return confirm("Удалить операцию? Действие необратимо!");  
     }  
     ```  
   - Внедрить уведомления о низком балансе.  

7. **Мультивалютность**  
   - Интегрировать API курсов валют (ЦБ/OpenExchangeRates):  
     ```python  
     exchange_rate = requests.get(f"https://api.exchangerate.host/convert?from=USD&to=RUB").json()['result']  
     ```  
   - Хранить операции в оригинальной валюте + эквивалент в RUB.
